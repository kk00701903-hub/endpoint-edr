# 상용 제품 벤치마크 — CrowdStrike Falcon · Genians (2026-10-02)

목표: 두 제품이 공통으로 갖춘 "엔드포인트를 보고 판단하는" 기능을 **상용 제품 품질**로 갖춘다.
이 시스템은 회사 내부 전용이고 **수동형(PC 를 바꾸지 않음)** 이라, 두 제품의 "막고 고치는" 기능은 일부러 넣지 않는다.
비교는 각 회사의 공개 제품 소개 수준이며, 세부 기능은 제품 버전·라이선스마다 다르다.

## 1. 비교 대상

| | CrowdStrike Falcon | Genians | 이 시스템 |
|---|---|---|---|
| 성격 | 클라우드 EDR/XDR 플랫폼(모듈 단위 판매) | 국내 NAC(Genian NAC) + EDR(Genian EDR) | 사내 전용 수동형 엔드포인트 모니터링 |
| 에이전트 | 커널 센서, 차단·격리 가능 | NAC 에이전트·EDR 에이전트, 차단·격리 가능 | 사용자 모드 서비스, **읽기 전용**(가드레일 `scripts/check-passive.sh`) |
| 배포 | SaaS | 구축형·클라우드 | 구축형(Supabase 자체 설치 또는 클라우드) |
